# Feedback-driven core fixes, 2026-09-08

Release candidate; production verification is recorded below after deployment.

## Behavior

The existing critic now distinguishes connective progress narration from a
method, informative result, incident or developed reaction. It can select a
stronger complete moment already present in its source window. Scanner recall,
models, call count and the final publishability filter are unchanged.

A segment with isolated internal zero-duration tokens can retain a certified
first-word onset. Its text, node indices, opaque ending and reliable-word status
remain unchanged. All start-moving paths retain segment boundary confidence;
invalid bounds, empty text and unreliable first/last words cannot certify starts.

Under the existing active reframe safety switches, broad center-cropped shots
without surviving faces use the existing full-frame fit over blur. The sidecar's
minimum column count for 70% of edge energy is compared with portrait capacity.
This is composition evidence, not object recognition. It works independently of
saliency-shadow telemetry. For static single-face shots, an observed late
face cannot impose its crop on a preceding broad insert: that prefix is fitted
in full, preserving the original crop afterward. Existing duration, sampling
cadence and shot-count bounds apply. Music, stream and dynamic trajectories
retain their existing behavior. Whole-shot saliency is conservative evidence
for the prefix; this is not semantic classification of the insert.
